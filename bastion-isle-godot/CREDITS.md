# Bastion Isle v3 - Credits

All code, models, sounds and UI are original and generated procedurally at run time (GDScript): buildings,
units, ships, aircraft, trees, rocks, terrain, particles and sound effects are built from primitives, so the
project contains no third-party models, fonts or audio.

## Engine

Made with Godot Engine 4.3 (MIT licence, https://godotengine.org/license).

The art direction imitates the general feel of cozy mobile strategy games; no assets, characters, names or UI
from any existing game are used.
